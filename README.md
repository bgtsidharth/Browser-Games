# Browser-Games

A collection of interactive, physics-based browser games.

## 🌊 Games

### 1. Water Ring Toss (Handheld Nostalgia Toy)
- **Location:** [`water-ring-toss/index.html`](water-ring-toss/index.html)
- **Description:** A browser recreation of the classic handheld water ring toss toy with realistic buoyant hydrodynamics, dual rubber bellows pump impulses, 3D toroidal ring geometry, solid rod deflection, and peg-threading mechanics.
- **Controls:**
  - `A` / `◄ Left Arrow`: Left pump jet
  - `D` / `► Right Arrow`: Right pump jet
  - `T` / `Space`: Tilt / shake toy
  - `R`: Reset / scatter rings
